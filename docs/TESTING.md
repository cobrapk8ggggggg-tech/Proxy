# الاختبارات

## التشغيل محليًا

```bash
pip install -r requirements-dev.txt
python -m pytest -q
npm ci
npm run check:ui
npx playwright install --with-deps chromium webkit
npm run test:browser
```

أنشئ `.venv` أولًا حسب README؛ إعداد Playwright المحلي يستخدم `.venv/bin/python`. داخل CI يستخدم Python مباشرة.

الخادم المستخدم لاختبارات الواجهة هو `tests/browser_server.py`: واجهة FastAPI وقاعدة SQLite حقيقيتان مع محاكاة المزوّد الخارجي فقط. مسار `/__reset` موجود داخل خادم الاختبار وحده، ولا يوجد في التطبيق الإنتاجي. صور العرض في docs تحتوي حسابات توضيحية من fixtures.

## النتائج المحلية النهائية

- 56 اختبار Python ناجحًا.
- 20 اختبار واجهة ناجحًا: 10 على Chromium و10 على WebKit. اختبارات الواجهة تشمل الكمبيوتر وWebKit بحجم iPhone 13، وقياسات 320 و768 بكسل، وفصل أوضاع ChatGPT والتثبيت وغياب بيانات API عن ذاكرة PWA.
- فحص أسماء Python غير المعرّفة وفحص صياغة JavaScript ناجحان.
- صُورت الواجهة على الكمبيوتر والهاتف باستخدام حسابات اختبار، دون بيانات المستخدم.
- نجح بناء Docker والتشغيل وتسجيل دخول الإدارة وحفظ حساب ثم إعادة التشغيل مع استعادته من volume؛ انظر [docker-verification.json](docker-verification.json).

## نطاق الاختبارات

- ChatGPT: اكتشاف حساب opaque token، رؤوس المصادقة، sidebar وprojects وقائمة محادثات المشروع، أحدث parent، metadata المشروع، التفكير، الرد النهائي بدل مقاطع التحليل، رفض الرد الناقص، رفع الملفات دون تسريب ترويسات المصادقة إلى التخزين.
- Gemini: استخراج بيانات الجلسة ونماذج الحساب وترويساتها، RPC المحادثات والسياق، تحديثات الرد النهائي والكوكيز؛ عدم كشف الرموز الداخلية في لوحة الحساب.
- DeepSeek Worker: قائمة النماذج والجلسات، parent بقيمة صفر، خيارات التفكير والبحث وأخذ العينات، فشل الخدمة والرد الفارغ والقطع بطول الإخراج.
- Qwen: النموذج المختار واستمرار السياق وتمييز قناة الرد النهائي، وأخطاء الشبكة.
- API: استقلال المحادثات، المتابعة بالتاريخ الكامل، التعارض عند التاريخ المتطابق، المشاريع، idempotency، المفاتيح والصلاحيات والإلغاء، التشفير وتحديث التوكن، JSON أدوات متداخل وtool outputs، Responses وتخزينه الاختياري، الصور والملفات ورفض الطلبات غير الصالحة.
- SDK الرسمي: Chat Completions وResponses بنوعي الاستجابة العادية وSSE.
- الواجهة: كل الأقسام، أحجام الكمبيوتر وiPhone في WebKit، اختيار المشروع وجلب محادثاته وحفظه، تفعيل وتعطيل فقرات Gemini، إنشاء المفتاح وطلب API به، إنشاء المسار وتجربته، تحديث التوكن وإعادة الربط وعدم عرضه في بيانات الإدارة.

تستخدم الاختبارات الثابتة HTTPX MockTransport لعزل الخدمة الخارجية. نجاحها لا يعادل صلاحية توكن حساب حقيقي.

## التحقق الحقيقي

ملف [live-gemini-result.json](live-gemini-result.json) تقرير من اختبار حساب Gemini المقدم بتاريخ 2026-10-19: جلب نموذج واحد و50 محادثة، إنشاء محادثة اختبار، تلقي الرد والمتابعة في المحادثة نفسها بنجاح. لا يحتوي التقرير بيانات الدخول أو أسماء المحادثات أو نصوصها أو معرفاتها.

يمكن إعادة اختبار حساب باستخدام:

```bash
# Set GEMINI_COOKIE_HEADER securely in your environment, then:
python scripts/live_smoke.py --provider gemini
# Explicitly creates a real conversation and sends two short test messages:
python scripts/live_smoke.py --provider gemini --send-test --output live-result.json
```

المتغيرات الأخرى: `CHATGPT_ACCESS_TOKEN` و`DEEPSEEK_ACCESS_TOKEN` و`QWEN_ACCESS_TOKEN`. يمكن تمرير مسار ملف كوكيز خاص عبر `GOOGLE_COOKIES_FILE`؛ يقرأ النص ولا ينفذ ملف shell.

أضيف اختبار ChatGPT حقيقي لاحقًا بالتوكن الذي قدمه المستخدم؛ انظر [اختبار الأوضاع](live-chatgpt-modes.json). لم تتوفر توكنات حقيقية لـDeepSeek أوQwen؛ تحقق هذين المزوّدين قائم على الاختبارات المعزولة. لم يُشغَّل تطبيق OpenMinis الأصلي على iPhone فعلي، بل روجع بروتوكوله من المصدر واختُبرت الواجهة في WebKit. لم يُختبَر فصل كامل حقيقي بهذا البروكسي الجديد؛ فحص Gemini الحقيقي كان رسالتين قصيرتين، بينما مسار الفقرات اختُبر بنصوص طويلة واستجابات معزولة. لا تعني هذه الاختبارات ضمان عدم تغيّر خدمات الحسابات لاحقًا.

تُشغّل GitHub Actions الاختبارات والعرض في المتصفحين عند كل push وpull request وتحفظ تقرير المتصفح وصور الفشل سبعة أيام.

أضيفت اختبارات فصل أدوات التطبيق عن أدوات ChatGPT، وكشف الاستدعاءات الداخلية دون إعادة POST، والسماح بها في وضع البيئتين، وظهور مصدر التنفيذ في JSON وSSE وResponses، وحفظ الخيار في المتصفحين. شمل اختبار حساب مجاني حقيقي تنفيذ عمل داخلي وقراءة ملف عبر عميل منفصل؛ انظر [التفاصيل والحدود](TOOL_ENVIRONMENTS.md).

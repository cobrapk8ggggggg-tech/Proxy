# توافق العملاء والمزوّدين

راجعنا كود [OpenMinis/OpenMinis](https://github.com/OpenMinis/OpenMinis) عند الالتزام `b4c0661d5631ebab4d1a2e6f3fd4c805d4030a6c`، خصوصًا `OpenAIProvider.swift` و`OpenAIAgentProvider.swift` و`OpenAIModelsAPI.swift` وبناء عناوين الطلبات. لم نشغّل تطبيق iOS الأصلي على جهاز فعلي.

| الواجهة | السلوك |
| --- | --- |
| `GET /v1/models` | المسارات المفعّلة المسموحة لمفتاح العميل فقط |
| `POST /v1/chat/completions` | رسائل نصية، system/developer، تاريخ الأدوات، `max_completion_tokens`، استجابة عادية أو SSE |
| `POST /v1/responses` | نصوص وصور وملفات، function calls/outputs، تعليمات، `previous_response_id`، `store:false`، أحداث SSE مسماة |
| `POST /v1/files?model=ALIAS` | multipart، ملف حتى 10MB، مرتبط بالمفتاح وحساب المزوّد، حذف محلي عبر DELETE |
| `POST /v1/images/generations` | Qwen فقط، `n=1` و`response_format=url` |
| `POST /v1/accounts/register` | تسجيل صريح لتوكن حساب بمفتاح بروكسي صالح؛ يظهر الحساب معطّلًا إلى أن يفعّله المدير |

المصادقة للعملاء بمفتاح بروكسي فقط. لا تُفسّر ترويسة Authorization تلقائيًا على أنها توكن حساب؛ هذا يمنع خلط صلاحيات العملاء بأسرار المزوّد. عند الانتقال من البروكسي القديم أضف حساب Qwen في اللوحة وأنشئ مفتاح عميل جديدًا.

الأدوات محاكاة نصية فوق بروتوكولات الحسابات، ويعلن `/models` ذلك في `capabilities.tools=emulated`. تُفحص المعاملات بمخطط JSON، وتُحفظ call IDs، ويعيد البروكسي استدعاء الأداة إلى العميل ليقوم العميل بتنفيذها؛ لا ينفذ البروكسي أوامر أدوات محليًا. نجاح اتباع المخطط يعتمد أيضًا على النموذج.

SSE يحافظ على معرف ثابت للمخرجات ويعيد finish_reason و`[DONE]` وفق الواجهة. التنفيذ الحالي ينتظر الرد الكامل ويتحقق منه قبل تقسيمه إلى أحداث، مع نبضات انتظار؛ لا يدّعي بث كل توكن فور توليده. عند طلب usage تُعاد `null` لأن واجهات الحساب لا توفر أرقام فوترة موثوقة.

الصور تقبل data URLs أو ملفات سبق رفعها بمفتاح العميل. لا يجلب الخادم روابط صور عشوائية من الإنترنت. لا يدعم الصوت أو embeddings أو batch أو بحث ملفات OpenAI أو المخرجات المنظمة الصارمة؛ يُرفض الطلب غير المدعوم بوضوح.

| المزوّد | اختيار النموذج | محادثات | مشاريع | إعدادات خاصة |
| --- | --- | --- | --- | --- |
| ChatGPT | من حساب المستخدم | عامة أو داخل المشروع؛ جديدة أو متابعة أو ثابتة | اكتشاف تلقائي واختيار | مستويات التفكير التي يعلنها النموذج؛ ملفات وصور |
| Gemini | من الحساب ومستوى الاشتراك | اكتشاف ومتابعة | غير مدعومة بهذه الواجهة | نموذج الحساب؛ ملفات؛ وضع ترجمة الفقرات اختياري |
| DeepSeek Telegram Worker | من `/v1/models` | جلسات Worker ومتابعة parent | غير متاحة | التفكير والبحث وtemperature وmax_tokens |
| Qwen | من قائمة الخدمة | إنشاء ومتابعة | غير متاحة | التفكير والبحث ورفع الملفات وتوليد الصور بحسب الخدمة |

حد الطلب 24MB، الملف 10MB، 8 عمليات توليد متزامنة، والحد الافتراضي 120 طلب API في الدقيقة لكل مفتاح. لا يُعاد POST تلقائيًا عند خطأ الشبكة حتى لا تتكرر الرسائل أو التكلفة. يمكن للعميل استخدام `Idempotency-Key` لنتيجة ناجحة مخزنة ساعة؛ اختلاف المحتوى مع نفس المفتاح يعيد 409.

تنتهي ملفات الربط وResponses بعد 24 ساعة، وبيانات مطابقة المحادثات بعد 30 يومًا عند التنظيف؛ لا تُحذف المحادثات الأصلية من موقع المزوّد. `store:false` يمنع تخزين نص Responses الكامل محليًا، مع بقاء بصمة التاريخ وحالة الربط المشفرة اللازمة للاستمرار والمحادثة الأصلية لدى المزوّد.

لا يوجد ضمان توافق مطلق مع كل تطبيق أو استمرار بروتوكولات الويب دون تغيير. قيود الاشتراك والحساب ومكافحة الروبوتات تبقى من جهة المزوّد.
